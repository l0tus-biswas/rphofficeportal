How It Works
  1. Create a Printful account and set up a store
  2. Add your business card products to the store (with designs already applied)
  3. Generate an API key: Dashboard → Developer → API Keys
  4. Paste the API key and store ID here, then save
  5. Test the connection to confirm it works
  6. Enable the feature — agents will immediately see your store products
How agents use it:
  • They browse your Printful store products (with images & pricing)
  • Select a variant and enter shipping address
  • Orders go to your Printful dashboard as drafts for you to confirm
